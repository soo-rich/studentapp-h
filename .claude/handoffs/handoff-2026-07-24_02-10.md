- **Décisions d'architecture de la session** (ressort orchestrateur) :
  1. `PUT /students/me/profile` est un **vrai PUT** : champ optionnel absent → `null`/`[]`.
  2. Mapper de profil **unique et partagé** (fonction pure exportée), consommé par `ProfileService` et `ModerationService`.
  3. Pas d'écran de détail d'urgence — traitement inline. Inconvénient assumé : **pas de deep-link** vers une demande. Si le besoin apparaît, ajouter `GET /moderation/urgent-requests/{id}` au contrat plutôt que bricoler côté front.
  4. **Material** pour tous les champs de sélection/cases à cocher. Exception documentée : `<input type="time">` natif, car `MatTimepicker` impose un `DateAdapter` alors que le contrat attend des chaînes `HH:mm`.
  5. **URL d'API configurable** via proxy de dev : `API_TARGET=http://localhost:3001 npm start`.

- **Environnement de dev opérationnel** (reproductible) :
  - Postgres : `cd studentapi && docker compose up -d postgres` (port **54329**, volume dédié). Ne **pas** lancer le compose entier : ses ports MinIO (9000/9001) sont déjà pris par d'autres conteneurs de la machine.
  - API : `PORT=3001 pnpm run start:dev` — le port 3000 est occupé par une app **Next.js d'un autre projet** de l'utilisateur (ne pas la tuer).
  - Front : `API_TARGET=http://localhost:3001 npx ng serve --port 4201` — un serveur préexistant occupe 4200 (`pkill -f "ng serve"` est sans effet sous Git Bash/Windows).

- **Pièges techniques découverts** :
  - Angular : sur un composant Material dans un `FormArray`, `[attr.id]` est **écrasé** par le host-binding interne (`MatCheckbox`/`MatSelect` ont leur propre `@Input() id`) → utiliser `[id]`.
  - Proxy Angular : `load-proxy-config.js` **exige** un `context` tableau de chaînes ; `pathFilter` est écrasé par la clé en format objet. Le seul discriminant utilisable est `bypass`.
  - Restauration après mutation : `git checkout --` sur un fichier **non suivi** ne restaure pas l'état muté, il ramène à HEAD (un validateur s'est fait piéger et l'a signalé). Consigne désormais dans les briefs : capturer le contenu avant mutation, réécrire, vérifier par checksum.
  - Bash : `UID` est une variable **readonly** — ne pas l'utiliser comme nom de variable dans les scripts de test.
  - Encodage : `curl` depuis Git Bash sous Windows corrompt les accents (U+FFFD) avant l'envoi. Passer par un fichier écrit en UTF-8 (`--data-binary @payload.json`).

- **Process** : le gate `require-validation.sh` bloque la fin de tour tant qu'un validateur n'a pas rendu — d'où de longues séquences d'attente. Ne pas lancer plus d'agents que nécessaire ; jamais de validateur combiné multi-tâches (1 validateur = 1 marqueur).
